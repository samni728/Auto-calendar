# Auto Calendar Web UI

This directory contains the responsive Next.js Web/PWA client for Auto Calendar.

本目录包含 Auto Calendar 的 Next.js 响应式 Web/PWA 客户端。

For complete setup, architecture, OAuth, network-access, and license information, see the [project README](../README.md) and [Shareware License](../SHAREWARE.md).

完整的安装、架构、OAuth、网络访问和许可说明，请参阅[项目 README](../README.md)与[共享软件许可](../SHAREWARE.md)。

```bash
npm install
npm run dev
npm run lint
npm test
```
